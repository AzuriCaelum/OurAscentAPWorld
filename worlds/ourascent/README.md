# Our Ascent - Archipelago Mod

NOTE: This mod is currently early in development. Please report any bugs in the Our Ascent channel in #future-game-design on the Archipelago discord server.

NOTE 2: The mod should work in public multiworlds, but I haven't exhaustively tested it yet. Be aware that you may experience desyncs or crashes.

## Setup

1. Back up your saveData.egg, this is in Users/___/AppData/LocalLow/Noobilator7/Our Ascent on Windows.
2. Download and install Bepinex from https://docs.bepinex.dev/articles/user_guide/installation/index.html, then follow the installation instructions, making sure that the config folder was successfully created. Bepinex version 5.4.23.x is recommended.
3. Download the Our Ascent Archipelago mod from the releases page and unzip it to the plugins folder.
4. Start the game. You should now see a login popup on the main menu.

## Important Information

- As of now, the game randomizes equipment and augments into the multiworld, as well as unlocks for specific stories. Checks are individual enemy kills, buying equipment, and killing bosses.
- For now, the only way to goal is to complete every single story present in your world.
- There is an option for the number of random stories to include in your yaml file. The "Last Chapter" option exists, but only chapter one is implemented. This option is present for future-proofing.
- The mod does not currently support deathlink.
- There are quite a few visual bugs with the mod, mostly with equipment, that affect clarity. Those will be the focus in the near future.
- Because of the above, it is recommended to use Universal Tracker to track which checks are available. If an item is not purchaseable and doesn't show an enemy to kill to drop it, it is one of the enemies you have not killed yet.
- Achievements are not currently supported as checks with the mod, and it is very unlikely that this will change for a long time.
- For syncs, it's recommended to have one story per ~2 hours
